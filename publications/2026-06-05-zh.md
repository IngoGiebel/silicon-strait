ROK 的 δ 在 `+0.0515` 落入预先承诺盲区间 `[+0.05, +0.10]`,超出地板 `+0.0015`。9/27 ±5td 锚点扰动落于 `+0.05` 之下 (按 Nisaba §5 [Source #2]) 意味着区间内状态脆弱:与合法锚点日期模糊性 (DUV 公告生效 vs 发布、LAI 选举日 vs 就职、PRC 港口费宣告 vs 生效日) 同量级的日历微扰,可将 ROK 翻出盲区间。实质性解读分两部分。**第一部分 (佐证):** M-25-1 完成了 Day-25 H25.1 所言之事 — 公司级 ROK 的文本轴 δ 为正,且在预测盲区间内。**第二部分 (限定):** 佐证为 *边际*,Day-26+ 工作必须 (a) 接受边际性并将其作为方法论脚注记录 (q-day26-2 默认路径),或 (b) 迭代 schema 或方法论以浮现更稳健的 ROK 信号。H25.1 与 H26.1 的数值一致性 (孤立 `+0.0546` vs 跨基底 `+0.0515`) 意味着边际性 *不是* 跨基底掩码惯例的产物 — 它是公司级 ROK 信号本身的属性,在两种独立测量协议下复现。

### §4.4 — US (SPY):语料库底部的基线佐证

US 的文本轴 δ 在 `+0.0342` 妥稳落于 `[−0.05, +0.05]` 盲区间内,复制了 Day-24 的 `+0.0342` SPY × TSM 观测 [Source #4]。US 按预测保持语料库底部位 (US 携带 `coupling_textual=INDIRECT` 与 `autonomy=DORMANT`,均指向语料库最小的文本轴信号)。US 是 H26.1 中唯一其预先承诺预测无复杂化干净落地的基底。

## §5 — 边际性与 ±5 交易日锚点敏感性

Nisaba 审计 §5 [Source #2] 在同一 harness 下、其他一切不变下,对 ROK × TSM 配对执行了 `{−5, 0, +5}^3 = 27` 案例锚点扰动网格。结果:

| 统计量 | 值 |
|---|---:|
| 原 ROK δ (按预注册锚点) | +0.0515007346 |
| 网格内最小 ROK δ | +0.0239 (DUV −5, LAI +5, PRC 0) |
| 网格内最大 ROK δ | +0.0684 (DUV +5, LAI 0, PRC −5) |
| 低于 `+0.05` 地板的案例 | **9 / 27 (33%)** |
| 高于 `+0.10` 天花板的案例 | 0 / 27 |
| 在 `[+0.05, +0.10]` 内的案例 | 18 / 27 (67%) |

边际性不对称:在现实锚点扰动下,ROK 可跌出区间下界,但不能超出区间上界。这是按 Nisaba 审计 §5 给出的发布安全措辞:"ROK 在预注册锚点下变得为正且勉强在区间内,与 Day-25 公司级信号一致,但区间内状态在锚点微移下不稳定。"脆弱性观察强化 q-day26-2 默认项 — 在方法论文件中加入"边际佐证"脚注。

扰动网格的次级观察:不对称主要由 DUV ±5 与 LAI ±5 敏感性驱动,而非 PRC ±5。PRC −5 与 PRC +5 分别在 `+0.0523` 与 `+0.0515` 均落于区间内。此日历不对称读解与 H25.1 逐锚点发现 (Day-25 §4.3) 一致 — PRC_2025 承担整个池化抬升;PRC 锚点对 ±5 td 扰动稳健,因信号足够强,小日历位移不威胁裁决底层贡献。DUV 与 LAI 携带较弱贡献,±5 td 扰动可翻转符号。
